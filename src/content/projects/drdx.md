DrDx.Me hosts the web versions of primerJinn, URAdime, spotPCR, stilPCR, the hissPCR primer designer and CountFU, next to pipelines for nanopore UMI data, whole-genome sequencing and RNA-seq, and a set of lab calculators. Some pipelines need access on request.
